# 📊 Excel Sales Dashboard – Mini Project

This project is a **formula-based Excel Dashboard** built using functions like  
`SUMIFS`, `AVERAGE`, `COUNTIFS`, charts, and KPI cards.  
It showcases sales performance across regions, categories, months, and products.

---

## 🚀 Features of the Dashboard

### ✅ **1. KPI Summary**
- Total Sales  
- Total Profit  
- Average Profit Margin  
- Number of Orders  

### ✅ **2. Visual Charts**
- 📈 Monthly Sales Trend (Line Chart)  
- 📊 Sales by Region (Column Chart)  
- 📊 Sales by Category (Bar Chart)  
- 🏆 Top 5 Products (Column Chart)  

### ✅ **3. Excel Skills Used**
- Excel Tables  
- SUMIFS  
- COUNTIFS  
- AVERAGEIFS  
- LARGE + INDEX  
- Line / Bar / Column Charts  
- Dashboard formatting & layout
